## External dependencies

57 of 209 skills reference something outside the repo. A skill with `none` runs on Claude alone — no keys, no network services.

- **env** — environment variables you must set (API keys and tokens)
- **MCP** — an MCP server that must be connected
- **pkg** — a pip/npm package the skill installs or imports
- **API** — a third-party HTTP API the skill calls

Detected by static scan of each skill's files; treat it as a strong hint, not a contract. A skill listing an API key will degrade or fail without it.
